herdeck puts each [herdr](https://herdr.dev) workspace on a key of the deck, coloured by state: blocked, working, done or idle, with blocked ones first. Tap a key to jump to that workspace, or hold it to see what the agent is doing. On macOS it also sits in the menu bar with the same counts, so it's useful without the deck plugged in.

Install it with Homebrew on macOS or Linux: `brew install gancio-xyz/tap/herdeck`. Not affiliated with Elgato.
